# ClientFlow

ClientFlow is a small-business CRM SaaS for managing leads, contacts, deals, tasks, and customer activity in one workspace.

## Status

UNDER DEVELOPMENT 

MVP development.

Current phase: Phase 3 — Foundation.

## Core Stack

- TanStack Start
- React
- TypeScript
- Tailwind CSS
- Supabase
- PostgreSQL
- Supabase Auth
- Git + GitHub

## Core Product

Users belong to workspaces.

Workspace members can manage:

- Leads
- Contacts
- Deals
- Tasks
- Activities

Access is controlled by workspace membership and role.
